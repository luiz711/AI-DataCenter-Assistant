# 🖥️ AI Data Center Assistant

An AI-powered assistant built with **Python**, **Streamlit**, and the **OpenAI API** to help data center technicians troubleshoot infrastructure, generate SOPs, summarize incidents, and answer technical questions.

## 🚀 Current Features

- 💬 AI chat assistant
- 🧠 Conversation history
- 🖥️ Data center system prompt
- 📂 Professional Streamlit interface
- 🔧 Quick tools sidebar
- 🔒 Secure API key management with `.env`

## 🛠️ Technologies

- Python
- Streamlit
- OpenAI API
- Git
- GitHub
- python-dotenv
